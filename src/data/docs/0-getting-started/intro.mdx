## What is RelaGit?

RelaGit is a modern graphical [git](https://git-scm.com) client. RelaGit enables you to manage your source code in infinite ways, as it offers extensible workflow (plugin) and style (theme) APIs.

RelaGit offers a sleek, modern interface that is easy to use and understand. It is built with [SolidJS](https://www.solidjs.com) and [Electron](https://www.electronjs.org), and is available for Windows, macOS, and Linux.

## Why RelaGit?

The main benefit of RelaGit is that it has been built with entirley open-source tools and has built-in support and encouragment for hacking your client to your liking. Find something that isn't right? You can [change it](/redirect/github) yourself or [submit an issue](/redirect/github) and we'll check it out.
