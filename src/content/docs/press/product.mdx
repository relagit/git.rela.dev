## Origin

RelaGit was created in 2023 by <At client:load name="TheCommieAxolotl"/> in an attempt to create a simpler, better looking Git client.
The resulting prototype was shelved [for around 4 months](https://rela.dev/blog/8-months-counting) before being picked up again in September of 2023 and worked on emphatically since.

New features and improvements are being added every day, and the client is expected to be released on February 10th, 2024.

## Differences

RelaGit offers a full-featured plugin system, which we call workflows. This allows users to pick and choose optional functionality to add to their client, without having to use a separate program.

Alongside plugins are themes, which allow users to customize the look and feel of the client to their liking.

We offer a few [official](https://npmjs.com/org/relagit) plugins, but anyone can create their own and publish them to the [npm](https://npmjs.com) registry under the `relagit` keyword.

[Learn more about creating and installing workflows.](/docs/workflows/creating-workflows)
