    <BentoItem icon="workflow" heading='What is RelaGit?' size='large'>
    RelaGit is a modern graphical <a href="https://git-scm.com" target="_blank">git</a> client. RelaGit enables you to manage your source code in infinite ways, as it offers extensible workflow (plugin) and style (theme) APIs.

    RelaGit offers a sleek, modern interface that is easy to use and understand. It is built with <a href="https://www.solidjs.com" target="_blank">SolidJS</a> and <a href="https://www.electronjs.org" target="_blank">Electron</a>, and is available for Windows, macOS, and Linux.
    </BentoItem>
    <BentoItem icon="light-bulb" heading='Tip' highlight>
    You can navigate this documentation via the sidebar, the control buttons at the bottom of this page, or by pressing the <kbd>←</kbd> and <kbd>→</kbd> keys on your keyboard.
    </BentoItem>
    <BentoItem icon="command-palette" heading='Getting Started'>
    To get started with RelaGit, you can download the latest release from the [download page](/download). Once you have downloaded the installer or bundle, run it and follow the instructions.
    </BentoItem>
    <BentoItem icon="question" heading='Why RelaGit?' size='large' highlight>
    The main difference between RelaGit and other Git Clients is that it comes with a workflow system with encouragment for hacking your client to your liking. Find something that isn't right? You can [change it](/redirect/github) yourself or [submit an issue](/redirect/github) and we'll check it out.
    </BentoItem>
</DocsBento>
