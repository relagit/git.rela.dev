## What is RelaGit?

RelaGit is a modern graphical [git](https://git-scm.com) client. RelaGit enables you to manage your source code in infinite ways, as it offers extensible workflow (plugin) and style (theme) APIs.

RelaGit offers a sleek, modern interface that is easy to use and understand. It is built with [SolidJS](https://www.solidjs.com) and [Electron](https://www.electronjs.org), and is available for Windows, macOS, and Linux.

## Why RelaGit?

The main difference between RelaGit and other Git Clients is that it comes with a workflow system with encouragment for hacking your client to your liking. Find something that isn't right? You can [change it](/redirect/github) yourself or [submit an issue](/redirect/github) and we'll check it out.

## Getting Started

> [!NOTE]
> {''}
> RelaGit is currently **in beta**. This means that it is not yet feature complete and may contain bugs. If you encounter any issues, please [submit an issue](/redirect/github) on GitHub.

To get started with RelaGit, you can download the latest release from the [download page](/download). Once you have downloaded the installer or bundle, run it and follow the instructions.
